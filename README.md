
Queen

A peer-to-peer electronic cash system

Queen is an open-source electronic cash system built around a peer-to-peer network and a mineable blockchain.

Currency: QUIN
Address Prefix: "1QN"
Block Reward: 50 QUIN
Halving Interval: 230,000 blocks

Status

Queen is under active development.

The project is focused on a simple, transparent blockchain implementation that can be run and verified using ordinary hardware.

Features

- Peer-to-peer blockchain
- Proof-of-work mining
- UTXO-based transactions
- Cryptographic transaction signatures
- Open-source implementation
- Mineable native currency: QUIN

Project

This repository contains the source code for the Queen blockchain and its supporting tools.

More documentation will be added as development continues.
